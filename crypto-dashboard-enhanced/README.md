# Crypto Dashboard Enhanced

An interactive, real-time dashboard for meme coins and the top 50 cryptocurrencies.

## Features

- **Tabbed interface**: Switch between “Meme Coins” and “Top 50 Crypto”.
- **Live charts**: Visualize market cap, sentiment, and performance.
- **Dynamic tables**: Search, sort, and filter coins.
- **Sentiment analysis**: Visual cues for social sentiment on meme coins.
- **Price alerts**: Set custom price alerts with modal dialogs.
- **Responsive design**: Works on desktop and mobile.
- **Dark mode support**: Automatically adapts to system theme.

## Stack

- Pure HTML/CSS/JS
- [Chart.js](https://www.chartjs.org/) for rich visualizations
- No backend required (all data simulated for demo)

## Usage

1. Open `index.html` in your browser.
2. Use the tabs to switch views.
3. Search/sort in the tables, set price alerts, and interact with real-time updates.

> **Note:** All prices and data are simulated/randomized for demonstration. For real data, connect to a live API.

## File Structure

- `index.html` — Main dashboard UI
- `style.css` — Responsive and theme-aware styling
- `app.js` — Dashboard logic, state, and interactivity
