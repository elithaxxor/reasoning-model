# Reasoning Model Repository

This repository contains two distinct programs, each in its own subfolder:

- [`crypto-dashboard-enhanced`](./crypto-dashboard-enhanced): An interactive cryptocurrency dashboard web app.
- [`trader99`](./trader99): An advanced batch trading signal generator and analysis toolkit using AI and financial data science.

## Programs

### 1. Crypto Dashboard Enhanced

A modern, real-time web dashboard for monitoring meme coins and top 50 cryptocurrencies. Features interactive charts, tables, search/sort/filter, sentiment scores, and price alerting. Built with HTML, CSS, JavaScript, and Chart.js.

See [`crypto-dashboard-enhanced/README.md`](./crypto-dashboard-enhanced/README.md) for details.

### 2. Trader99

A Python toolkit for batch trading signal generation, analysis, and reporting. Integrates with multiple exchanges, computes TA indicators, invokes multiple OpenAI models for multi-perspective analysis, and outputs structured JSON and HTML reports. Supports parallel processing and batch evaluation for multiple trading pairs.

See [`trader99/README.md`](./trader99/README.md) for details.
